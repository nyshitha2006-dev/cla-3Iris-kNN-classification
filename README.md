## Results Summary
- Dataset: Iris (150 samples, 4 features, 3 classes)
- Split: 70 % train / 30 % test (stratified)
- Model: `KNeighborsClassifier(n_neighbors=5)`
- **Test Accuracy: 97.78 %**
- Only 1 misclassification (virginica → versicolor)
